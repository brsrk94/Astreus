# Astreus v0.1.1

This release adds a portable Linux AppImage and refines the UI/UX.

## New in v0.1.1
- Added downloadable AppImage build for x86_64 Linux
- Gruvbox responsive UI polish
- Outfit font bundled in app resources
- GDebi-like workflow improvements
- Post-install actions:
  - Check Dependencies
  - Uninstall Package

## Download files
- `Astreus-Package-Downloader-x86_64-v0.1.1.AppImage`
- `astreus-source-v0.1.1.tar.gz`
- `SHA256SUMS-v0.1.1.txt`

## Notes
- AppImage is built on Linux x86_64.
- Root-level package operations still require `pkexec` on target machine.
